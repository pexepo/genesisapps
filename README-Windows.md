# Запуск на Windows — с нуля

Пошаговый гайд, как поднять бота и **сайт-форму Genesis** на Windows 10/11. Рассчитан
на то, что ты раньше не работал с командной строкой. Всё, что в блоках `вот так`, —
это команды для **PowerShell**: копируешь, вставляешь, жмёшь **Enter**.

> Создание бота в Discord, получение токена и ID ролей/канала описано в основном
> **[README.md](README.md) → «Шаг 1»**. Здесь — только запуск на твоём ПК.

---

## Что понадобится

- Windows 10 или 11.
- 15 минут.
- Токен бота и нужные ID из Discord (см. README.md → Шаг 1).

---

## Шаг 1. Установить Python

1. Скачай Python с <https://www.python.org/downloads/windows/> (кнопка «Download Python 3.x»).
2. Запусти установщик. **ОЧЕНЬ ВАЖНО:** на первом экране внизу поставь галочку
   **«Add python.exe to PATH»**, потом жми **Install Now**.
3. После установки **открой заново** окно PowerShell и проверь:

```powershell
py --version
```

Должно показать `Python 3.11` или новее. Если «py не распознан» — переустанови Python
с галочкой PATH (пункт 2).

---

## Шаг 2. Открыть PowerShell в папке проекта

1. Открой **Проводник** и зайди в папку с файлами бота (где лежат `bot.py` и папка `web`).
2. В адресной строке Проводника (вверху) набери `powershell` и нажми **Enter** —
   откроется PowerShell уже в этой папке.

Проверь, что файлы на месте:

```powershell
dir
```

Ты должен увидеть `bot.py`, `requirements.txt` и папку `web`.

---

## Шаг 3. Создать окружение и установить зависимости

Создаём изолированное окружение `.venv` и ставим в него библиотеки бота. Глобальный
Python не трогается.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
pip install -r requirements.txt
```

После активации слева появится `(.venv)` — значит окружение включено.

> **Ошибка про «выполнение сценариев отключено»** при активации? Один раз выполни:
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```
> ответь `Y`, затем снова `.\.venv\Scripts\Activate.ps1`.
>
> Либо используй классическую командную строку **cmd** вместо PowerShell — там
> активация делается так: `.\.venv\Scripts\activate.bat`.

**В каждом новом окне** перед запуском бота снова активируй окружение
(`.\.venv\Scripts\Activate.ps1`), находясь в папке проекта.

---

## Шаг 4. Заполнить `.env`

`.env` — файл с настройками (токен, ID канала и ролей). Создаём из шаблона и открываем
в Блокноте:

```powershell
copy .env.example .env
notepad .env
```

Впиши свои значения (что где брать — README.md → Шаг 1):

- `DISCORD_TOKEN` — токен бота;
- `FORUM_CHANNEL_ID` — ID форум-канала для заявок;
- `REVIEWER_ROLE_ID` — роль, которой можно жать Accept/Decline;
- `ROLE_CHOICE_1..4_ID` / `_NAME` — какие роли выдавать и подписи кнопок.

Сохрани (`Ctrl + S`) и закрой Блокнот.

> `.env` содержит пароль бота — **не выкладывай его в интернет и не отправляй никому**.

---

## Шаг 5. Запустить бота

```powershell
py bot.py
```

Должно появиться примерно так:

```
HTTP-сервер слушает http://0.0.0.0:8080  (сайт: есть, POST /apply, POST /submit)
Бот вошёл как ИмяБота#1234
Форум-канал найден: #заявки
```

> При первом запуске Windows может спросить про доступ в сеть («Брандмауэр
> Защитника Windows») — разреши, чтобы сайт открывался.

Открой в браузере **<http://localhost:8080/>** — увидишь **сайт-форму Genesis**. 🎉
Заполни тестовую заявку: в форум-канале за пару секунд появится пост с кнопками.

Чтобы остановить бота — вернись в PowerShell и нажми **`Ctrl + C`**.

> `localhost` работает только на твоём ПК. Чтобы форму могли открыть другие — Шаг 6.

---

## Шаг 6. Открыть сайт для других (туннель)

Нужен публичный адрес. Самый простой путь — **ngrok** (бесплатно).

1. Скачай ngrok для Windows с <https://ngrok.com/download> и распакуй `ngrok.exe`
   (удобно — прямо в папку проекта).
2. Зарегистрируйся на ngrok.com, скопируй токен со страницы *Your Authtoken* и
   выполни один раз:

   ```powershell
   .\ngrok.exe config add-authtoken ВСТАВЬ_СВОЙ_ТОКЕН
   ```

3. Бот должен быть запущен (Шаг 5) в одном окне PowerShell. Открой **второе** окно
   PowerShell в папке проекта и запусти туннель:

   ```powershell
   .\ngrok.exe http 8080
   ```

4. ngrok покажет строку вида `Forwarding https://abcd-12-34.ngrok-free.app -> http://localhost:8080`.
   Этот `https://...`-адрес — ссылка на твой сайт-форму, **давай её заявителям**.

> Бесплатный адрес ngrok меняется при каждом перезапуске. Для постоянного адреса —
> Cloudflare Tunnel (`cloudflared`) или деплой на сервер: см.
> **README.md → «Шаг 5. Деплой на VPS»**.

---

## Держать бота включённым

Пока окно PowerShell с `py bot.py` открыто — бот работает. Закроешь окно или выключишь
ПК — бот остановится. Для постоянной работы (24/7) лучше арендовать недорогой
Linux-сервер с автозапуском: **README.md → Шаг 5**.

---

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `py не распознан как ...` | Python без PATH — переустанови с галочкой «Add python.exe to PATH» (Шаг 1), перезапусти PowerShell. |
| `CERTIFICATE_VERIFY_FAILED` при логине в Discord | Редко на Windows. Лечится переустановкой зависимостей: `pip install -r requirements.txt` (ставит `certifi`, бот подхватывает его сам). |
| Ошибка «выполнение сценариев отключено» | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` → `Y`, потом активируй заново (Шаг 3). |
| На `localhost:8080` пусто/«не удаётся подключиться» | Бот не запущен или упал — смотри сообщения в окне, где `py bot.py`. |
| Вместо формы текст «Сайт заявки не установлен» | Рядом с `bot.py` нет папки `web\` с `index.html` — запускай бота из корня проекта. |
| В логе `сайт: НЕТ` | То же самое — папка `web\` не найдена рядом с `bot.py`. |
| `Address already in use` / порт занят | Уже запущен другой `bot.py` на 8080. Закрой его или поменяй `PORT` в `.env`. |
| `ngrok.exe не найден` | Запускай с `.\` перед именем, находясь в папке с `ngrok.exe`, либо укажи полный путь. |
| Бот онлайн, но роль не выдаётся | Включи **Server Members Intent** и подними роль бота **выше** выдаваемых (README.md → Шаг 1). |
| Шрифты выглядят простыми | Сайт грузит шрифты с Google Fonts — нужен интернет; без него подставляется системный (это нормально). |

Готово. Когда сайт открывается по ngrok-ссылке и тестовая заявка долетает до
форум-канала — всё работает. 🚀

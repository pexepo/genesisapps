# Запуск на macOS — с нуля

Пошаговый гайд, как поднять бота и **сайт-форму Genesis** на Mac. Рассчитан на то,
что ты раньше не работал с терминалом. Всё, что в блоках `вот так`, — это команды:
копируешь, вставляешь в Терминал, жмёшь **Enter**.

> Создание бота в Discord, получение токена и ID ролей/канала описано в основном
> **[README.md](README.md) → «Шаг 1»**. Здесь — только запуск на твоём Mac.

---

## Что понадобится

- Mac с macOS 12 или новее.
- 15 минут.
- Токен бота и нужные ID из Discord (см. README.md → Шаг 1).

---

## Шаг 1. Открыть Терминал в папке проекта

1. Открой приложение **Терминал** (Spotlight: `⌘ + Пробел` → набери «Терминал»).
2. Перейди в папку с файлами бота. Самый простой способ: напиши `cd ` (с пробелом
   в конце), затем **перетащи папку проекта из Finder прямо в окно Терминала** —
   путь подставится сам. Нажми **Enter**.

```bash
cd /перетащи/сюда/папку/ezezez
```

Проверь, что ты в нужной папке — команда должна показать `bot.py` и папку `web`:

```bash
ls
```

---

## Шаг 2. Установить Python (если ещё нет)

Проверь:

```bash
python3 --version
```

- Если видишь `Python 3.11` или новее — отлично, переходи к Шагу 3.
- Если команда не найдена или версия старая — установи Python одним из способов:

**Способ А (рекомендую) — с сайта:** скачай установщик с
<https://www.python.org/downloads/macos/>, открой `.pkg`, жми «Далее». Затем
**закрой и снова открой Терминал** и проверь `python3 --version`.

**Способ Б — через Homebrew** (если он у тебя есть):

```bash
brew install python
```

---

## Шаг 3. Создать окружение и установить зависимости

Эти команды создают изолированное окружение `.venv` и ставят туда библиотеки бота
(`discord.py`, `aiohttp`, `python-dotenv`). Глобальный Python не трогается.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

После `source ...` слева в строке Терминала появится `(.venv)` — значит окружение
активно. **В каждом новом окне Терминала** перед запуском бота снова выполняй
`source .venv/bin/activate` (находясь в папке проекта).

---

## Шаг 4. Заполнить `.env`

`.env` — это файл с настройками (токен, ID канала и ролей). Создаём его из шаблона:

```bash
cp .env.example .env
open -e .env
```

Откроется TextEdit. Впиши свои значения (что где брать — README.md → Шаг 1):

- `DISCORD_TOKEN` — токен бота;
- `FORUM_CHANNEL_ID` — ID форум-канала для заявок;
- `REVIEWER_ROLE_ID` — роль, которой можно жать Accept/Decline;
- `ROLE_CHOICE_1..4_ID` / `_NAME` — какие роли выдавать и подписи кнопок.

Сохрани файл (`⌘ + S`) и закрой окно.

> `.env` содержит пароль бота — **не выкладывай его в интернет и не отправляй никому**.

---

## Шаг 5. Запустить бота

```bash
python bot.py
```

Должно появиться примерно так:

```
HTTP-сервер слушает http://0.0.0.0:8080  (сайт: есть, POST /apply, POST /submit)
Бот вошёл как ИмяБота#1234
Форум-канал найден: #заявки
```

Открой в браузере **<http://localhost:8080/>** — увидишь **сайт-форму Genesis**. 🎉
Заполни тестовую заявку: в форум-канале за пару секунд появится пост с кнопками.

Чтобы остановить бота — вернись в Терминал и нажми **`Ctrl + C`**.

> `localhost` работает только на твоём Mac. Чтобы форму могли открыть другие —
> сделай Шаг 6.

---

## Шаг 6. Открыть сайт для других (туннель)

Чтобы дать ссылку друзьям/заявителям, нужен публичный адрес. Самый простой путь —
**ngrok** (бесплатно).

1. Установи ngrok: скачай с <https://ngrok.com/download> (или `brew install ngrok`).
2. Зарегистрируйся на ngrok.com, скопируй свой токен со страницы *Your Authtoken*
   и выполни один раз:

   ```bash
   ngrok config add-authtoken ВСТАВЬ_СВОЙ_ТОКЕН
   ```

3. Бот должен быть запущен (Шаг 5) в одном окне Терминала. Открой **второе** окно
   Терминала и запусти туннель на тот же порт:

   ```bash
   ngrok http 8080
   ```

4. ngrok покажет строку вида `Forwarding https://abcd-12-34.ngrok-free.app -> http://localhost:8080`.
   Этот `https://...`-адрес и есть ссылка на твой сайт-форму — **давай её заявителям**.

> Бесплатный адрес ngrok меняется при каждом перезапуске. Для постоянного адреса —
> Cloudflare Tunnel (`cloudflared tunnel --url http://localhost:8080`) или
> полноценный деплой на сервер: см. **README.md → «Шаг 5. Деплой на VPS»**.

## Держать бота включённым

Пока окно Терминала с `python bot.py` открыто — бот работает. Если закрыть окно или
усыпить Mac — бот выключится. Варианты:

- **Просто** — оставь Терминал открытым, отключи автосон (Системные настройки →
  «Аккумулятор/Экономия энергии»).
- **Правильно** — разверни на сервере с автозапуском (`systemd`): README.md → Шаг 5.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `command not found: python3` | Python не установлен/не в PATH — вернись к Шагу 2, перезапусти Терминал. |
| `CERTIFICATE_VERIFY_FAILED` при логине в Discord | У Python с python.org нет корневых сертификатов. Обычно уже решено: `certifi` ставится из `requirements.txt`, и бот сам его подхватывает. Если ошибка осталась — переустанови зависимости (`pip install -r requirements.txt`) или разово запусти: Finder → Программы → «Python 3.x» → двойной клик по **Install Certificates.command**. |
| `zsh: command not found: ngrok` | ngrok не установлен или не в PATH — переустанови (Шаг 6). |
| На `localhost:8080` пусто/«не удаётся подключиться» | Бот не запущен или упал — смотри сообщения в Терминале, где `python bot.py`. |
| Сайт открылся, но вместо формы текст «Сайт заявки не установлен» | Рядом с `bot.py` нет папки `web/` с `index.html` — запускай бота из корня проекта. |
| В логе `сайт: НЕТ` | То же самое — папка `web/` не найдена рядом с `bot.py`. |
| `Address already in use` / порт занят | Уже запущен другой `bot.py`/процесс на 8080. Закрой его или поменяй `PORT` в `.env`. |
| Бот онлайн, но роль не выдаётся | Включи **Server Members Intent** и подними роль бота **выше** выдаваемых ролей (README.md → Шаг 1). |
| Шрифты выглядят простыми | Сайт подгружает шрифты с Google Fonts — нужен интернет; без него подставляется системный шрифт (это нормально). |

Готово. Когда сайт открывается по ngrok-ссылке и тестовая заявка долетает до
форум-канала — всё работает. 🚀
